# Superstore SQL Analysis Project

## Project Overview

This project analyzes the Superstore dataset using SQL. The objective is to explore sales performance, profitability, customer behavior, product performance, shipping efficiency, and business trends.

The analysis demonstrates practical SQL skills commonly used by Data Analysts to solve real-world business problems.

## Dataset

The dataset contains information about:

- Orders
- Customers
- Products
- Sales
- Profit
- Quantity
- Regions
- Ship Modes
- Order Dates
- Ship Dates

## Tools Used

- MySQL
- SQL

## Business Questions Solved

### A. Basic Data Exploration

- List all regions
- List categories and sub-categories
- Count unique customers

### B. Sales & Profit Analysis

- Total sales and profit
- Sales and profit by category
- Sales and profit by region
- Average sales per order
- Loss-making orders

### C. Customer Analysis

- Top customers by sales
- Top customers by profit
- Customers generating losses
- Customer count by segment

### D. Product Analysis

- Top products by sales
- Top products by profit
- Loss-making products
- Quantity sold by category
- Most profitable sub-categories

### E. Time-Based Analysis

- Monthly sales trends
- Monthly profit trends
- Yearly order counts

### F. Shipping Analysis

- Orders by ship mode
- Average delivery time
- Most profitable ship mode
- Least profitable ship mode

## Key SQL Concepts Used

## Project Outcomes

This project helps identify:

- High-performing products

These insights can help businesses improve profitability and operational efficiency.
